ШАБУР.EXE v2 — Cloudflare Workers

Файлы для корня GitHub-репозитория:
- worker.js (настоящее учебное API)
- wrangler.jsonc (настройки Cloudflare Workers)
- public/index.html (интерактивный сайт)
- public/assets/*.webp (12 изображений Шабура)

Публикация:
1. Загрузите содержимое этой папки В КОРЕНЬ репозитория GitHub.
2. При замене старой версии обязательно замените public/index.html и добавьте public/assets/*.webp.
3. В Cloudflare Workers подключите GitHub, оставьте Build command пустым, Deploy command: npx wrangler deploy.
4. После успешного развёртывания откройте главную страницу / и /api/health.
5. Из колледжа проверьте оба адреса и GET/POST через Postman. Доступность Cloudflare в РФ не гарантируется.

Для учащихся: на главной странице 5 миссий, подсказки, заметки с автосохранением, экспорт в txt.
Ни одна миссия не выполняет API-запросы вместо учащихся: запросы делаются в настоящем Postman.
Сервер stateless: POST проверяет данные и возвращает учебный результат, не сохраняет заказ в общую базу.
